Review the changes for bugs, security issues, performance problems, and adherence to project conventions.

Focus areas:
- Logic errors and edge cases
- Security vulnerabilities (injection, auth, data exposure)
- Performance (N+1 queries, unnecessary re-renders, large bundles)
- Error handling gaps
- Type safety issues
- Test coverage adequacy
- Accessibility (if UI code)
- Consistency with project patterns

For each issue, include: severity (critical/warning/suggestion), file:line, description, and suggested fix.
