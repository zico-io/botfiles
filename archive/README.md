# Archived tooling

`local-fleet/` preserves the retired macOS herdr/orbal-net fleet, its Apple
container image, plan pane, model proxy, Bob/Eve adapter and mission artifacts.
It is historical source, outside the T3 server's provisioning and CI gates.
Paths and commands in this archive describe the former layout and are not
supported entrypoints. Pi/MLX model serving and its provider configuration were
removed.

Bob/Eve-specific startup and connector code remains here for reference when
moving it into the owning application. It is no longer part of active botfiles
tooling. Server sessions run through T3 with Claude Code or Codex.
