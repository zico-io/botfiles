# tools/nix - flake and dev shell

- The repo is a flake (`flake.nix`, nixpkgs `nixos-26.05` only). Outputs: `devShells.default`, the botfile `checks`, and `formatter`; no packages or NixOS hosts. The `botfiles`, `jev-cli` and `t3code` packages were dropped: nothing installed them once sandbox-host lost its logins, and the sandbox image installs t3 from npm <source: flake.nix + yggdrasil services/sandbox/image/Dockerfile, 2026-10-29>
- sandbox-host, the TrueNAS guest that is yggdrasil's k3s sandbox pool node, moved to yggdrasil (gitlab percs/yggdrasil) with its rescue ISO, tailnet module and sops file: `nixos/` holds the flake, `secrets/sandbox-host.yaml` the ciphertext, `make sandbox-host` deploys, and its README section "Sandbox pool node (NixOS)" holds the VM, access and rescue facts. The moved system evaluates to the same derivation as botfiles' last one <source: nix eval of both flakes' toplevel drvPath, 2026-10-29>
- T3 Desktop and the T3 server must run the same version to pair: a `0.0.46-nightly` desktop against a `0.0.45` server fails with `UnknownBootstrapCredentialError` / HTTP 401 at `/oauth/token`. The sandbox image (yggdrasil `services/sandbox/image`) pins t3code to the desktop's version for this reason <source: live pairing reproduction 2026-10-11; carried over 2026-10-27>
